@app.post("/run")
def run():
    if "file" not in request.files:
        return "Missing file parameter", 400
    file = request.files["file"]
    filename = secure_filename(file.filename or "")

    # A new JSFxxk challenge!
    content = file.read().decode()
    if len(set(content)) > 5:
        return "Too many characters :(", 400

    filepath = os.path.join(session["user_dir"], filename)
    open(filepath, "w").write(content)

    try:
        proc = subprocess.run(
            ["bun", filepath],
            capture_output=True,
            timeout=2,
        )
        if proc.returncode == 0:
            return "Result: " + proc.stdout.decode()
        else:
            return "Error"
    except subprocess.TimeoutExpired:
        return "Timeout"

Initially it looks like we need to write JavaScript to read the flag with only 5 different characters. At least to my knowledge, we'd typically require at least 6 characters to do anything useful in vanilla JavaScript. However, there are examples where libraries or other small additions to the language can be leveraged to reduce the number of characters needed. For example, https://aem1k.com/five/, uses JQuery UI features to execute any JavaScript with only 5 characters.

With this in mind, I started looking for features of Bun that might allow us to do something similar. While I didn't find anything particularly useful for this idea, I did stumble across this: https://bun.com/docs/runtime/shell#sh-file-loader.

For simple shell scripts, you can use Bun Shell instead of /bin/sh. Pass a file with the .sh extension to bun:

bun ./script.sh

We can use this, since the filename we use during the file upload is only sanitised using secure_filename, which does not remove or change our file extension.

With this new approach, we just need to read the flag using at most 5 different characters in a shell context. Importantly, this also means we have state, since one file upload can rely on the result of the previous. Finding a way to read the flag required a lot of trial and error, but I came up with the below.

cp /* */* # UPLOAD 1: cp /flag.txt into current directory. This will be `sandbox/<random-sandbox-folder/`.
pr */*/*  # UPLOAD 2: read files in */*/*

The pr command was found while looking through /usr/bin in the container for binaries with short names.

$ pr --help
Usage: pr [OPTION]... [FILE]...
Paginate or columnate FILE(s) for printing.

It turned out to be perfect for this challenge, as it simply paginates a file (or files) and prints to stdout.
